Ovaj projekt osmišljen je kao praktični poligon za svladavanje temelja Godot enginea. Kroz igru upravljamo likom uz primjenu trenja za realistično kretanje, sakupljamo predmete i bodove te ostvarujemo interakcije sa zidovima i preprekama u sceni. Potrebno je sakupiti sve bodove.

Upravljanje (Tipke)
W / Tipka prema gore – Kretanje prema gore
A / Tipka lijevo – Kretanje u lijevo
S / Tipka prema dolje – Kretanje prema dolje
D / Tipka desno – Kretanje u desno
